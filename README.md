# Network-Security-Project-WiFi-Evil-Twin-and-KRACK-Attack-
Overview 
This project explores two major WiFi attacks: the Evil Twin attack and the KRACK 
attack.It demonstrates how attackers can intercept traffic and exploit 
weaknesses in WPA2. 
Learning Objectives 
• Understand WPA2 security mechanisms 
• Perform Evil Twin attack 
• Understand KRACK attack on 4-way handshake 
• Analyze WiFi traffic 
• Evaluate defenses 
Environment Setup 
• Attacker machine (Kali Linux) 
• USB WiFi adapter supporting monitor mode 
• Victim device 
• Access point or hostapd setup 
Project Tasks 
Part 1: Evil Twin Attack 
1. Create rogue access point with same SSID 
2. Force victim to connect 
3. Capture traffic or credentials 
4. Analyze captured data 
Part 2: KRACK Attack 
5. Capture WPA2 4-way handshake 
6. Replay message 3 
7. Force key reinstallation 
8. Demonstrate packet decryption or replay 
Expected Deliverables 
• Evil twin demonstration 
• KRACK attack results 
• Traffic analysis 
• Demo video
